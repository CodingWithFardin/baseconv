# baseconv

Convert integers between bases 2..36 with prefix detection.

```
python baseconv.py 0xff --to 10
```

Runs on 3.11 and newer. Stdlib only.

Files: `baseconv.py`, `tests/test_baseconv.py`.

Tests: `tests/test_baseconv.py`. The suite is the specification; start there if the code is unclear.
